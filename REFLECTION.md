1. After the browser receives the url, first it needs to figure out where the website is located. So it gets the domain name from the url, and translates it into an ip address. Now the browser knows where the website is located at, so it sends a HTTP request to the web server using the ip address. In this case, it reaches Github. The Github server receives and processes the request, and it sends a HTTP response back. The server gives the requested data and file to the browser. The browser gets the resources from the server, and finally it renders the website.
